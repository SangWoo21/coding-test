# 🔥 Algorithm

매일 알고리즘 문제를 풀고 기록하는 저장소입니다.

## 🎯 목표
- **백준 골드 1** 달성 (solved.ac 기준)
- 하루 1~2문제 꾸준히 풀기
- 풀이마다 아이디어와 실수한 부분을 주석으로 기록하기

## 🛠 사용 언어
- **C** (주 언어, 임베디드 직무 대비)
- Python (이전 풀이: 프로그래머스)

## 🗺 로드맵
| 단계 | 목표 티어 | 유형 |
|---|---|---|
| 1 | 실버 5~3 | 입출력, 정렬(qsort), 스택·큐 직접 구현, 브루트포스, 누적합 |
| 2 | 실버 2~1 | DFS·BFS, 백트래킹, 그리디, 이분 탐색, 기초 DP |
| 3 | 골드 5~4 | DP 심화, 힙 구현·다익스트라, 투 포인터, 유니온 파인드 |
| 4 | 골드 3~1 | 위상 정렬, MST, 플로이드, LIS, 비트마스크 DP, 세그먼트 트리, 시뮬레이션 |

## 📁 구조
- `백준/` : 티어별 → 문제별 폴더
- `프로그래머스/` : 레벨별 → 문제별 폴더
- [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)로 자동 업로드합니다.

## 📝 풀이 규칙
- 코드 맨 위에 `유형 / 아이디어 / 주의할 점`을 주석으로 남깁니다.
- 30분 넘게 막히면 힌트를 보고, 다음 날 안 보고 다시 풀어 봅니다.
- C 자료구조(스택, 큐, 힙 등)는 라이브러리 없이 직접 구현합니다.
